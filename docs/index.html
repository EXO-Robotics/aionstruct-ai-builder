00 / Premise

Minecraft Editor is useful. It should not be mandatory. AIONSTRUCT lets an AI reason about architecture in a finite blueprint, then turns that intent into a structure file with inspection artifacts attached.

Every image below is a source-bound engineering preview. Runtime placement and client appearance remain separate proof gates.

02 / The method

An inspectable path
from words to world.

The AI works inside a bounded format. Each stage produces evidence the next stage can verify—without pretending a static check is a Minecraft playtest.

  1. 01

    Describe

    Write an architectural brief with rooms, routes, silhouette, materials, and lighting intent.

  2. 02

    Author

    Express the build as strict, finite JSON operations—boxes, walls, lines, stairs, openings, anchors.

  3. 03

    Inspect

    Expand to final voxels and render 3D boards, floors, elevations, cutaways, and light maps.

  4. 04

    Gate

    Fail on blocked routes, narrow apertures, unsupported lights, stale previews, or missed quality targets.

  5. 05

    Compile

    Write deterministic Bedrock bytes, reopen every voxel independently, then qualify exact bytes in BDS.
